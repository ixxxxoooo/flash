# Flash 高阶功能开发方案

作者：ygw　日期：2026-10-15

## 目标

在没有付费开发者账号的前提下，为 Flash 补齐 Surge 风格的高阶能力：增强模式（TUN）、MitM、URL / Header 重写、Map Local、脚本、HTTP 报文查看。

## 约束与可行性

- Network Extension 需要付费账号，不可用。改用 mihomo 自带 TUN，并以 root 运行（管理员授权安装 LaunchDaemon）。
- MitM / 重写 / 脚本在应用内的 Swift 引擎里实现；脚本使用系统 JavaScriptCore。
- 根证书由用户授权后写入系统钥匙串并信任。
- 不能对 mihomo 重新签名（否则进程识别失效）。

## 总体架构

```
客户端 → mihomo(6152 / TUN)
            │  命中 [MITM] 主机名
            ▼
      规则指向 FlashMitM（本地 socks5 出站）
            ▼
   FlashMitM 引擎：TLS 终结 → 重写 / Map Local → 脚本 → 报文记录
            ▼  上游经 mihomo 独立入站 mitm-up（规则中以 NOT IN-NAME 排除，避免回环）
         mihomo → 订阅节点
```

## 模块设计

| 模块 | 位置 | 说明 |
| --- | --- | --- |
| TUN | `Core/PrivilegedCore.swift`、`ConfigGenerator` tun/dns 段 | root LaunchDaemon，管理员授权 |
| 证书 | `MitM/CertificateAuthority.swift` | 生成根 CA，动态签发叶子证书 |
| 引擎 | `MitM/MitMServer.swift` | 本地 socks5 入口，TLS 终结，HTTP/1.1 解析与转发 |
| 重写 | `MitM/RewriteEngine.swift` | URL Rewrite、Header Rewrite、Map Local |
| 脚本 | `MitM/ScriptEngine.swift` | JavaScriptCore，兼容 `$request` `$response` `$done` 等 |
| 报文 | `MitM/HTTPRecorder.swift` | 环形缓冲，单条 ≤ 1MB |
| 界面 | `Flash/Features` | 设置页（TUN、证书）、请求页「报文」标签 |

## 配置语法

沿用 Surge 语法：`[MITM]`、`[URL Rewrite]`、`[Header Rewrite]`、`[Map Local]`、`[Script]`。

## 测试策略

- 单元测试：重写、Map Local、证书、JS API、TUN 配置生成。
- 集成测试：本地 HTTPS 服务经 MitM 验证重写和脚本。
- 性能：请求页 3000 行流畅；引擎 1000 并发连接稳定；内存抽样。

## 构建发布

`scripts/build.sh` 产出 ad-hoc 签名的 `.app` 与 DMG，未公证，首次需右键打开。
